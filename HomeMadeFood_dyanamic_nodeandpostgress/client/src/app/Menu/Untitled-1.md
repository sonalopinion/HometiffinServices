
| Hook                   | Remember with this word | Easy meaning                      |
| ---------------------- | ----------------------- | --------------------------------- |
| `useState`             | **Store**               | Store and update data             |
| `useEffect`            | **After**               | Do something after rendering      |
| `useContext`           | **Share**               | Share data between components     |
| `useRef`               | **Remember**            | Remember a value or access DOM    |
| `useMemo`              | **Result**              | Remember a calculated result      |
| `useCallback`          | **Function**            | Remember a function               |
| `useReducer`           | **Manage**              | Manage complex state              |
| `useLayoutEffect`      | **Before**              | Run before browser paint          |
| `useImperativeHandle`  | **Control**             | Expose selected methods to parent |
| `useId`                | **Unique**              | Generate unique IDs               |
| `useTransition`        | **Priority**            | Mark UI updates as non-urgent     |
| `useDeferredValue`     | **Delay**               | Delay updating a value            |
| `useSyncExternalStore` | **Subscribe**           | Subscribe to external data        |
